GOAL: engine turns a requirement into a verified, security-audited, signed, deployed microservice artifact. Python 3.12, strict typing (mypy --strict, Pydantic).
HOST (Windows): orchestrator, agents, NetworkX, FastAPI backend, PWA frontend (React+Vite), signing keys, API keys. Docker Desktop (WSL2) runs: sandbox (disposable Ubuntu 24.04), Redis Streams, Qdrant. Sandbox never sees keys, Redis or Qdrant.
NO relational DB. State = hash-chained JSONL event log + content-addressed files + Qdrant + NetworkX (saved as JSON).
LLM: LiteLLM Router; one model string per role in config/models.yaml (I fill IDs). Roles: requirements=MiniMax-M3.1-Flash (fallback Gemini 3.8 Flash); coder=MiniMax-M3.1-Flash (fallback Qwen3.8-27B Groq); debugger=gpt-oss-120b (Groq) then Qwen3.8-27B; test_designer=GPT-4.1 or gpt-5.4-mini (fallback Gemma 4 31B). Per-model rpm/tpm limits, retries with backoff, daily token counter. No local models. No Critic agent.
AGENT OUTPUTS: only Pydantic artifacts: RequirementSpec, TaskPlan, CodePatch, TestSuite, ExecutionReport, DebugPatch. Orchestrator is deterministic code.
SOPs: YAML files (sop_lightweight, sop_modify_repo, sop_full_module) define steps: agent, input, output schema, retries, gates. Workflow engine executes them.
FLOW: requirements -> ADMIN APPROVAL 1 (spec) -> Coder and Test Designer run IN PARALLEL (asyncio.gather) -> Test Designer done -> ADMIN APPROVAL 2 (tests) -> when code ready AND tests approved: sandbox run -> debug loop (max 3: gpt-oss x2, then Qwen3.8; fresh prompt each time with code slice, last ~2K chars of error, attempt history, temp 0.0/0.3/0.5) -> security gate -> acceptance gate -> hash+sign -> canary deploy. Approvals logged with admin id, decision and hash of approved artifact. Rejected tests: rerun Test Designer only. Spec changed: discard code and tests.
READ ACCESS: all agents may query NetworkX, Qdrant, logs read-only via orchestrator retrieval (tenant-filtered, secrets redacted, top-k, wrapped as data not instructions). Test Designer must NOT see current task's code until TestSuite is frozen. Agents never write.
RISK TIER: rules (payroll, tax, balances, access rights, PII, data mutation = high) + AST re-check of generated code; may only be raised. High = strongest model, extra gates.
SECURITY GATE: before run: AST allowlist (default deny; block eval/exec/__import__/subprocess/os.system), Bandit, Ruff S, Semgrep, detect-secrets, Prompt Guard + regex on requirement text, declared-vs-used permissions. After run: pip-audit, final scan, runtime security_events. Block on high/critical.
ACCEPTANCE GATE: tests pass, mypy --strict clean, coverage >=80, security clean, every requirement id has a passing test, deterministic (seeded Faker/Hypothesis, run twice, no flaky), human approval for high risk.
SIGNING: manifest.json (SHA-256 per file, root hash, test and security report hashes, model versions, log head hash), Ed25519 signature; private key only on host in signer; verify before deploy.
BUS: Bus interface, Redis Streams backend; signed envelope {@context,@type,id,correlation_id,tenant_id,sender,timestamp,payload,signature}; verify signature + tenant + schema on receipt.
LOGS: audit event log (hash-chained, checkpoint-signed, only orchestrator writes); access log (logins, approvals); conversation store (every LLM call, redacted, text in files referenced by hash); episodic memory in Qdrant (verified work only, per-agent field); current stage derived from events.
NETWORKX: repo graph (files, classes, functions, tests; edges imports/defines/calls/tests/produced_by, built with ast.parse, never executes code) + domain graph (entities like Employee, Attendance; edges references/belongs_to; code->entity "handles"). Test data = Faker synthetic only.
DEPLOY: Docker Compose + nginx/Traefik weighted router, new version side by side, health check, 10%->50%->100%, auto-rollback, log every step.
APP: FastAPI thin gateway (no ORM/SQL), SSE live view, JWT + Argon2 login, approval screens. Frontend is a PWA for desktop and mobile.
